# Repository workflow

- Treat this repository as the source of truth for the territory map simulator.
- After implementing and validating an in-scope change, commit it and push it to the configured GitHub remote unless the user explicitly asks for local-only work.
- Preserve user data and unrelated working-tree changes.
- Never commit credentials, tokens, installed dependencies, PID files, or temporary analysis previews.
- Keep generated Excel samples and visual QA outputs when they document or verify a user-facing export feature.
