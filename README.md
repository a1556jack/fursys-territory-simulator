# 퍼시스 권역 편성 시뮬레이터

2025년 지역별 퍼시스 매출·시공비와 전국 시군구 지도를 결합한 로컬 웹앱입니다.

## 실행

가장 쉬운 방법은 `시뮬레이터_실행.cmd`를 더블클릭하는 것입니다. 기본 주소는 `http://127.0.0.1:4317`이며, 이미 다른 앱이 사용 중이면 4327 이후의 빈 포트를 자동으로 선택합니다.

PowerShell에서 다음 명령을 실행합니다.

```powershell
.\start_simulator.ps1
```

실행 후 표시되는 주소를 브라우저에서 엽니다.

## 주요 기능

### 권역지략 게임 모드

시뮬레이터 상단의 `⚑ 권역지략 게임` 또는 `game.html`에서 실행합니다. `권역조정4(8월 버전)`의 배정 지역 85개를 대상으로 인력과 지역을 재배치하는 훈련용 프로토타입입니다. 첫 접속에는 쉬운 룰 안내가 나오며 상단 `플레이 방법`에서 다시 볼 수 있습니다. 실제 시군구 경계의 입체 지도, 과부하 표시, 예비 인력 투입·회수, 권역 간 지원, 지역 이관, 명령 되돌리기, 결산 보고서를 제공합니다.

- `따라하기`: 실제 버튼으로 이현석→김용훈 인력 1명 지원과 서대문구 이관을 각각 연습합니다. 단계별 버튼 강조와 행동 전후 설명을 제공하며 중간에 나가도 이어할 수 있습니다.
- `오픈 모드`: 명령 횟수와 종료 턴 제한 없이 실험합니다. 원할 때 다음 수요 상황을 적용하고 1인당 Capa 가정을 변경할 수 있습니다.
- `스토리 모드`: 3개 장, 턴당 명령 6회로 진행합니다. 각 장의 목표를 달성하면 다음 장이 열립니다. 참모 힌트와 현재 턴 시작점으로 재시도하는 기능을 제공합니다.

스토리 목표는 1장 인력 지원·커버율 98% 이상·과부하 1개 이하, 2장 지역 이관·커버율 99% 이상·인력 균형 90점 이상, 3장 커버율 100%·과부하 0개·인력 균형 90점 이상입니다. 스토리와 따라하기는 연간 Capa 50백만원 가정으로 고정해 진행합니다.

게임 진행은 모드별로 별도 브라우저 저장공간에 자동 저장됩니다. 기존 버전의 게임은 원래 저장값을 보존한 채 오픈 모드로 이어집니다. 상단 `모드 선택`에서 전환하며 다른 모드의 진행을 덮어쓰지 않습니다. `훈련안 내보내기`로 저장한 JSON은 기존 시뮬레이터의 `불러오기`에서 확인할 수 있습니다. 원본 시나리오와 금액은 플레이로 바뀌지 않습니다.

인원 46명과 예비 3명, 1인당 연간 정상 시공비 5,000만원 Capa는 게임 가정입니다. 게임 가정 화면에서 오픈 모드의 Capa를 바꾸고 새 작전을 시작할 수 있습니다. 업무량은 2025년 연간 정상 시공비의 대리 지표이며 월 수치는 연간 금액 ÷ 12입니다. 두 번째 수요 상황의 서울 +12%, 세 번째 상황의 서울 원복·경기 +10%는 훈련 사건입니다. 오픈 모드에서는 세 상황이 순환합니다. 이동 시간, 시공 시간, 품질, 실제 계절성은 반영하지 않습니다.

점수는 업무 커버율 45%, 인력 균형 35%, 인력 효율 20%로 계산합니다. 테스트는 `node test_game.mjs`와 `node test_game_modes.mjs`로 실행합니다. 배경은 이미지 생성 모델로 만든 장식용 디오라마이며 실제 지리 경계는 기존 지도 데이터를 사용합니다. 제작 정보는 `docs/territory-command-art.md`에 있습니다.

### 업무 시뮬레이터

- 지도와 목록을 이용한 지역 권역 이동 및 미배정 처리
- 지도 위 마우스 휠 확대·축소와 왼쪽 버튼 드래그 이동(페이지 스크롤과 분리)
- OpenStreetMap 실제 좌표 기반 한강 본류 표시
- 최초 편성 대비 변경 편성의 매출·시공비 비교
- 권역별 인원, 1인당 케파, 기준 지표 입력 및 초과 판정
- 권역 생성·삭제·이름·색상 변경
- 시나리오를 브라우저와 로컬 `data/saved_scenarios.json`에 함께 저장하고 JSON 가져오기·내보내기
- GitHub Pages 외부 공유 화면에서도 저장된 기본 시나리오 백업 6개 자동 제공
- 현재 시나리오의 권역 요약·지역별 시공결과금액·정상시공비·전체 합계를 XLSX로 추출
- 모든 활성 권역을 권역별 개별 시트로 구성한 XLSX 일괄 추출

## 데이터 주의사항

경인 데이터 기준으로 `강서구`는 서울특별시, `동구`와 `서구`는 인천광역시에 연결합니다. `중구`는 원본 시공결과금액과 정상시공비를 서울특별시 중구 90%, 인천광역시 중구 10%로 원 단위 합계가 보존되도록 배분합니다. 시도 정보만으로 판단할 수 없는 `고성군`, `남구`는 미배분 금액으로 별도 보존합니다.

한강 수계 선형은 OpenStreetMap 기여자 데이터를 사용하는 WaterwayMap GeoJSON을 기반으로 하며, 앱에 오프라인 데이터로 내장되어 있습니다.
